# QuizzApp

A Flutter true-or-false trivia app with six image-based categories. Each category
has 10 questions, immediate answer feedback, and a final score screen.

## Run the app

```sh
flutter pub get
flutter run
```

## Run tests

```sh
flutter test
```

Category questions and their image assets are defined in `lib/data/quizz_data.dart`
and `assets/`. Shared app colors are in `lib/theme/app_colors.dart`.
